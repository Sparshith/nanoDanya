# nanoDanya

Research code for training and evaluating small chess language models.

The public 10 MB challenge, forkable starter, rules, browser checker, and model
submissions live in [nanoDanya-challenge](https://github.com/Sparshith/nanoDanya-challenge).

Research experiments and benchmarks remain here. See [project state](knowledge/STATE.md)
and [benchmarks](benchmark/README.md).
