# LLM arena: nanoDanya vs API models, full games (2026-01-31)

Early full-game matches between nanoDanya (legal-masked) and API LLMs, played with
the January `arena/` rig (deleted 2026-07-04; this note is the surviving record).

Result: **9-0 for nanoDanya.**

| Opponent | Round 1 (no retries) | Round 2 (with retries) |
| --- | --- | --- |
| GPT-4o-mini | win (checkmate) | - |
| Claude 3.5 Haiku | win (illegal move) | - |
| Gemini 1.5 Flash 8B | win (illegal move) | - |
| GPT-4o | win (illegal move: Rb1) | win (checkmate, 40 moves) |
| Claude Sonnet 4 | win (checkmate) | win (checkmate, 46 moves) |
| Gemini 2.0 Flash | win (illegal move) | win (checkmate, 28 moves) |

Reading: without retries, most API models lose by illegal move before chess quality
even matters; with retries they play legal games and still lose by checkmate. This
was the first signal behind the raw-legality framing. Superseded methodologically by
the 2026-05-27 API legality comparison (per-position raw top-1 on shared positions,
newer models), which is the citable number. Full-game LLM play has no rig in the
repo anymore; benchmark/ covers API models via the legality mode only.
